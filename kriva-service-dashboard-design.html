Complex data, unread

The data exists. The morning scan still fails.

These are the patterns we see before a redesign starts — not a shortage of charts.

01

Scan failure

Metrics are on the page, but the shift question is buried under equal-weight widgets. Operators open the view and still ask Slack.

02

Widget sprawl

Every stakeholder request adds a chart. The layout never says no, so nothing stays primary, and new metrics land wherever there is space.

03

Spreadsheet workaround

Filters and tables do not match the questions leadership asks. Teams dump to CSV, rebuild the answer, and stop trusting the product view.

Information architecture

Hierarchy first. Charts second.

Name the questions, rank the widgets, then design the scan, the table, and the admin workflow that closes the loop.

  1. 01 · Questions

    Name the shift question

    What must be true in the first 90 seconds. Stakeholder chart requests wait until that answer sits above the fold.

  2. 02 · IA

    Rank the layout

    Primary scan, then density. Ops, admin, and exec are not the same screen — they share a kit, not a canvas.

  3. 03 · Scan

    KPIs, chart, table

    Signal, then evidence, then the row they act on. Filters land on the source record, not another export.

  4. 04 · Workflow

    Admin that finishes

    Assign, override, audit — a console operators can complete a task in, not a settings graveyard.

Dashboard UX

Ops, admin, and exec are not the same view

Real-time visibility for the desk. A table the admin can finish. A quiet summary leadership will actually open.

Exception-first ops

The shift question sits above equal-weight KPIs. Open exceptions are a list with owners, not a chart of “issues.”

  • Primary scan in the first viewport
  • Filters that resolve to a record
  • Density matched to a desk, not a projector

Admin that can actually run

Users, roles, and overrides in a table operators can finish — search, status, and an action on the row.

  • Task-complete layouts, not nested menus
  • Role context visible in the chrome
  • Errors that say what to do next

Quiet executive summary

One answer, a trend, and a path into the ops view. Leadership should not need the same density as the floor.

  • One primary metric, not twelve tiles
  • Exception count as the call to action
  • Drill-down into the ops scan, not a new export
