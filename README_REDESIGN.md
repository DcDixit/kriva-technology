## 🔧 Customization Guide

### Adjust Animation Speed
```css
.hero-float { animation: hero-float 6s ... }
/* Change 6s to desired duration */
```

### Change Colors
```css
/* All colors use design tokens - update in tokens.css */
--cta: #4F46E5;           /* Primary blue */
--blue-deep: #3730A3;     /* Secondary blue */
--paper: #F4F3EE;         /* Background */
```

### Modify Shadow Intensity
```css
box-shadow: 0 20px 60px -12px rgba(14,18,22,.25)
                                              ↑ Opacity
```

### Adjust Glow Effect
```css
.hero:before {
  background: radial-gradient(..., rgba(79,70,229,.05) ...);
                                                   ↑ Opacity
}
```
